# Cyber Us — Website

A simple responsive static website for the Cyber Us webcomic.

## Files

- `index.html` — main page
- `style.css` — visual design
- `script.js` — language switch and small interactions
- `assets/episodes/` — put comic/page images here later

## Before publishing

1. The Ko-fi support button and homepage footer link point to https://ko-fi.com/sketchcerberus. If the creator changes accounts, update both links in `index.html`.
2. Replace the placeholder artwork in `index.html` with your Cyber Us art.
3. Add episode thumbnails/images if you want them.
