# Cyber Us — Website

A simple responsive static website for the Cyber Us webcomic.

## Files

- `index.html` — main page
- `style.css` — visual design
- `script.js` — language switch and small interactions
- `assets/episodes/` — put comic/page images here later

## Before publishing

1. Open `script.js`.
2. Replace the Ko-fi `#` with your real Ko-fi URL.
3. Replace the placeholder artwork in `index.html` with your Cyber Us art.
4. Add episode thumbnails/images if you want them.
